# PatternProof product direction (Sept 2026)

## Doors
- `/choose-role` redirects to `/how-it-works`.
- Advocates, orgs, and attorneys create accounts. No request-access gate.
- Marketing pages stay public. Vault routes stay behind auth.

## Money
- Survivors: documenting, invites, live share, and the first court packet stay free.
- Attorneys pay for a workspace (notes, caseload, firm tools), not for opening one shared file.
- Optional contribution only after survivor signup; unlocks nothing.

## Thread
`ChronologyThread` is the chronology view: exact knots, approximate dashes, unresolved gaps, three clocks when present. Demo and live case should use the same component.

## Invite
`resolveInvite` never charges the survivor. Missing users get a review link plus optional self-serve signup.
