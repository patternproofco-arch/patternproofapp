Notification failure rolls back all of them. Every eligible subscription and founding trial contributes to the billing decision; paid-through cancellation is preserved, another valid subscription prevents an incorrect pause, and live records take precedence over sandbox records. Revoked/expired grants cannot resume. The UI selects the strongest current paid plan instead of a newer cancelled plan.

Missing metadata uses the stored owner; conflicting ownership and failed provider/database reads request retry. Update events can create the row before the creation event arrives. Replayed one-time purchases retain their original signed event date and paid-year end.
- Integrated #201's public-route tracker restrictions, self-hosted fonts and lazy Stripe loading. Private first loads and invite links request no Google/Stripe assets in browser fixtures. Repository controls do not disable Lovable's hosting-injected analytics; see release gates.
