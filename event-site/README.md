# Survivor Warrior Awareness Walk site

A standalone React/Vite event website for Survivor Warrior's Philly's 3rd Annual Domestic Violence Awareness Walk.

## Event details

- Thursday, October 1st, 2026
- Registration: 9:00 AM
- Walk: 10:00 AM
- Benjamin Franklin Bridge, Front Street, Philadelphia, PA
- 5K community walk with an Information & Resource Spotlight

## Run locally

From this directory:

```bash
pnpm install
pnpm dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
pnpm build
```

## Social graphics

Ready-to-download graphics are in `public/social-graphics/`:

- Square feed: 1080×1080
- Story: 1080×1920
- Landscape: 1200×628

A ZIP archive is included at the repository root as `survivor-warrior-social-graphics.zip`.
